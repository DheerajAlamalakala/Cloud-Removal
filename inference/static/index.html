Samples are random held-out test patches (scenes the model never trained on), grouped by cloud coverage. They are not hand-picked. "Cloud region" uses a pseudo-mask built from the cloudy/clear RGB difference, not a ground-truth cloud label, so it also catches haze, shadow and some change between acquisition dates. RGB preview uses a fixed 2.5x exposure boost and standard sRGB display gamma. The exported GeoTIFF keeps the original georeferencing and reflectance scale (x10000).
